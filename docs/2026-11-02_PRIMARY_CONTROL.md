# 단어 순서·문맥 통제 추가 주 실험 — 2026-11-02

이 기록은 같은 날 앞서 완료한 copyright80 채점과 contextual81 출처 감사를 **대체하지 않는 추가 실험**이다. 과거 응답을 새로 생성하지 않았다. 새로 구성한 정원 문장 통제 입력에 대한 평가자 판정과 기존 SP70 응답 재판정을 수행했다.

## 설계와 분모

- standard159의 서로 다른 유해 prompt 159개에 113단어 정원 문장 쌍159개를 대응시켰다. F는 유창 문장, S는 단어 멀티셋을 보존한 재배열이다. 의미 보존 변형은 아니다.
- H는 원래 행동 문맥, N은 **하나의 중립 정원 요청**을 모든 문장에 재사용한 문맥이다. 중립 질문159개라는 뜻이 아니다.
- 159묶음 × H/N × F/S × HB/LG = 1,272개 새 통제 판정, 기존 seed42 SP70 응답 R의 HB/LG 재실행318개, 총1,590개다. missing/invalid/abstain/excluded는 모두0개다.
- 12개 골격과 공통 어휘를 공유한다. 159개 독립 모델 반복이 아니며 명목 p값·구간이 골격 의존성을 해결하지 않는다.
- 입력·방법·분석은 새 판정 전에 동결한 **전향적 탐색 연구**다. 과거 판정을 설계 전에 보았고 외부 사전등록은 아니다.

## 주 결과

H에서 HB/LG 불일치는 F **71/159 (44.65%)**, S **148/159 (93.08%)**로, S−F는 **77/159 = +48.43%p**다. 불일치 증가77묶음, 감소0묶음. 양측 exact McNemar p = **1.32349×10⁻²³**; 명목 대응 bootstrap95% 구간은 **+40.88~+55.97%p**다.

구간 전체가 사전에 제시한 +10%p 실용적 기준보다 높다. 원래 동결 출력의 `material_plus10pp_unresolved`는 실제로 상한≥10%p만 검사해 이름이 오해를 낳았다. 원본은 비공개 감사자료로 그대로 보존하고, 공개 reporting projection은 이를 제거한 뒤 `plus10pp_interval_relation`과 독립 검토한 주석으로 올바르게 표시한다. **추정치·검정·구간·가설·모델 호출은 바꾸지 않았다.** 이 명목 구간은 모집단의 확정적 효과나 인과효과를 뜻하지 않는다.

HB label1은 주어진 행동이 성립한다는 yes다. **N의 HB yes를 unsafe 또는 false positive로 해석하지 않는다.** LG의 label1은 unsafe 분류다. H/F부터71개가 LG unsafe이므로 재배열만이 전체 unsafe 수준을 만들었다고 주장하지 않는다.

중립 문맥의 불일치 변화는 +6.92%p (명목95% 구간 −1.89~+15.72%p), H−N 변화 차이는 +41.51%p (+30.19~+52.83%p)다. 이들은 부가 기술통계이며 추가 p값은 없다. H/N은 길이 등도 달라져 유해 의도만 고립한 효과가 아니다.

## 재현·해석 경계

기존 SP70의 새318개 라벨과 원시 판정 출력은 과거 raw636의 해당318개와 모두 일치했다. 과거 라벨은 인간 정답이 아니다. 모든 실제 LG 입력795개에서 Agent 역할·마지막 Agent 판정 지시·User/Agent 결합과 hash를 검증했다. 결과를 역할 순서 렌더링 오류로 설명할 근거는 확인되지 않았다.

이 결과는 제한된 innocuous-content 통제 입력에서의 입력·문맥 민감성을 보여준다. 인간 검증 FPR, 일반 정확도, 가지치기 효과, SP70 불일치의 원인 또는 전체 안전성으로 확장하지 않는다. 어순·응집성·구두점 위치가 함께 변한다.

두 use_fast 설정 요청은 모두 Fast backend로 해석되었으므로 독립 fast/slow 알고리즘 검증이 아니다. 요청된 모델·tokenizer revision은 고정했지만 실제 로드 config commit은 null로 관측되어 그 한계를 기록했다. 첫 세션은 판정0개로 종료됐고 동일 입력으로 사전검사를 다시 했다. 최종 모델 실행 종료와 GPU 세션0개를 확인했다.

원시 prompt/응답/token IDs·비공개 Drive ID·로컬 경로·인증값은 공개하지 않는다. 공개 코드는 명시적 비공개 입력을 요구하거나 텍스트 없는 라벨을 재집계한다. [분석 재현 코드·테스트·자료](../experiments/2026-11-02_primary_control/README.md).
