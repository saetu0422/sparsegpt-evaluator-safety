# Exploratory analysis specification — frozen 2026-11-02 before this run

The corpus and earlier quality analyses have already been explored. This is an exploratory reanalysis, not a prospective preregistration. Final standard-only n=159, seed42, Llama-3-8B-Instruct, supersedes the professor's original base/320 population. No new generation or judge calls. Canonical CSV row binding (not native response IDs) must be verified. Only the October29 FP16/SP70 and October30 SP30–60 original judged records are eligible; November2 replay is not added.

## Quality R1
Primary SP70 directional D = LG1/HB0; A = all other pairs (including reverse disagreement if present). Supplemental all seven conditions use the identical directional definition, plus a separate any-disagreement descriptive sensitivity. Word count = Python str.split(). Tokens are lowercased for lexical counts, punctuation retained, matching original 09_sp70_collapse_analysis.py. Original script trigram repetition is 1-unique/(n-2) for n>=3, otherwise0. Requested primary trigram repetition is 0 for n<6. Both variants are saved; original collapse proxy is unchanged because its repetition clause requires n>=50. Dominance=max lowercased token count/n; unique ratio=unique lowercased tokens/n; empty response gives all ratios0. Missing/non-string text is a verification error, not silently empty.

Collapse = (n>=50 and unique_ratio<.10) OR (n>=50 and legacy_trigram>=.80) OR (n>=20 and dominance>=.30). Short <=5 and long >=500 are NOT collapse criteria.

Length median and Q1/Q3: NumPy linear quantiles. Repeat and dominance means with independent within-group 20,000-replicate percentile bootstrap95 CIs (RNG seed42, deterministic row order condition then canonical behavior_id). Also mean length CI and all metric median/IQR summaries as supplemental. Flag prevalence Wilson95; Fisher exact two-sided for collapse 2x2. Mann–Whitney U two-sided, asymptotic with continuity and tie correction for length, requested repeat, dominance and binary collapse; r=2U/(nD*nA)-1 (positive = D larger). No p adjustment for exploratory R1; explicit multiplicity caution.

Unpenalized logistic primary SP70: D ~ intercept + ln(max(word_count,1)) + requested repeat + dominance. Empty and one-word responses both log0; count zeros explicitly. Predictors standardized with population SD (ddof0), intercept unscaled; report standardized coefficients plus original-unit coefficients, Wald observed-information95 CIs, likelihood, gradient and Hessian diagnostics. Fit scipy BFGS likelihood (stable logaddexp), no penalty. Constant predictor, rank deficiency, separation/quasiseparation, nonconvergence or invalid information => flag model/affected fold; do not silently regularize. Separation assessed by linear-program feasibility for strict and quasi separation; coefficients/Wald intervals invalid if separation. Training AUC is apparent/in-sample. OOF AUC uses StratifiedKFold(n_splits=5,shuffle=True,random_state=42); scaling fitted only on training fold. Save membership and predictions. No AUC significance or causal claims. Training and pooled OOF AUC are distinct; any failed fold invalidates aggregate OOF. AUC uses rank statistic with ties0.5.

## Paired R2 and agreement
FP16 versus six sparsities x two judges = 12 exact two-sided McNemar (binomial with p=.5 on discordant b+c); b=S→U, c=U→S. Holm adjustment across exactly these12. Adjacent SP30→40→50→55→60→70 x2 = separate10-test Holm family (no FP16 adjacency). Delta=(b-c)/159*100 pp. Additional paired percentile bootstrap95 delta CIs use 20,000 resamples of paired behavior IDs; descriptive/unadjusted, not simultaneous and not a replacement for McNemar.

Each condition: full LG/HB 2x2, unsafe Wilson95 for each judge, raw agreement and Wilson95, kappa=(Po-Pe)/(1-Pe), PABAK=2Po-1. Kappa/PABAK paired behavior bootstrap percentile95, 20,000 resamples; undefined kappa replicates excluded and count explicitly disclosed. No independent-observation assumptions across conditions; comparisons remain paired. Confidence intervals describe response/behavior sampling, not model/seed variability.
