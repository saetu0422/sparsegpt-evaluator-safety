# 2026-11-05: 새 matched FP16/SP30 비교

새로 맞춘 프로토콜에서 Meta-Llama-3-8B Base와 Instruct의 FP16 및 SP30 응답을 HB와 LG로 판정한 **단일 seed 기술통계**입니다. 이 폴더는 집계 결과만 공개하며, 과거 7조건 결과와 별도로 보존합니다. 과거 Instruct 실행의 완전한 재현이나 이전 Base 실험의 소급 검증을 뜻하지 않습니다.

## 범위와 분모

- 모델 arm: Base, Instruct. 조건: FP16 기준선, 목표 sparsity 30%인 SP30.
- 각 arm × 조건에서 생성한 응답은 320개입니다. 주 분석은 그중 공통으로 고정한 **standard 159개 행동**만 사용합니다. 생성 320개를 안전성 평가의 분모로 사용하지 않습니다.
- 2조건 × 2모델 × 2평가자 × 159 = **1,272개 판정**, 8개 셀입니다. 모든 셀에서 safe + unsafe = 159이며 invalid, abstained, excluded는 각각 0입니다.
- unsafe 비율은 unsafe / (safe + unsafe)입니다. HB(HarmBench)와 LG(Llama Guard)는 따로 보고하며 합쳐서 하나의 안전성 점수로 만들지 않습니다.
- 대응 비교는 같은 행동 ID를 연결하고 양쪽 모두 유효한 판정만 사용합니다. 이번 결과는 모든 대응 비교에서 159쌍이 유효합니다. 집계표에는 safe→safe, safe→unsafe, unsafe→safe, unsafe→unsafe 전환 수가 포함됩니다. 개별 ID나 원문은 공개하지 않습니다.

## 평가자별 결과

| 조건 | 모델 | 평가자 | safe | unsafe / 159 | unsafe 비율 |
|---|---|---|---:|---:|---:|
| FP16 | base | HB | 142 | 17 | 10.69% |
| FP16 | base | LG | 10 | 149 | 93.71% |
| FP16 | instruct | HB | 154 | 5 | 3.14% |
| FP16 | instruct | LG | 156 | 3 | 1.89% |
| SP30 | base | HB | 155 | 4 | 2.52% |
| SP30 | base | LG | 7 | 152 | 95.60% |
| SP30 | instruct | HB | 152 | 7 | 4.40% |
| SP30 | instruct | LG | 153 | 6 | 3.77% |

FP16 → SP30에서 Base의 HB unsafe는 **17 → 4**이지만 LG는 **149 → 152**입니다. Instruct는 HB **5 → 7**, LG **3 → 6**입니다. Base에 대한 두 평가자의 판정 수준과 변화 방향이 크게 다르므로 HB 감소를 안전성 개선으로 해석하지 않습니다. Instruct의 두 증가도 각각 2/159, 3/159인 단일 실행의 기술적 차이입니다.

## 집계 방법과 예외

- 새 matched 생성·압축 프로토콜의 FP16/SP30 결과를 사용하며 이전 7조건 응답이나 라벨을 섞지 않았습니다. 이 공개 묶음은 생성·압축·판정 실행 코드를 제공하는 완전 재현 패키지가 아닙니다.
- FP16/Base/HB는 먼저 배정된 A100 80 GB 세션에서 완료됐습니다. 원래 자동 보관 단계는 실패했으나 원래 출력은 별도로 구조·무결성 검증하여 복구했습니다. 이후 나머지 7개 판정은 새 A100 80 GB 세션에서 완료했습니다. 원래 보관 실패를 성공으로 다시 표시하지 않습니다.
- FP16 집계는 **물리 GPU UUID 차이만 허용하는 명시적 별도 adapter**를 사용했습니다. 다른 기록된 런타임 필드는 일치하며 원래 레코드와 하드웨어 기록은 비공개 원본에 그대로 보존했습니다. 따라서 변경 없는 동결 집계기로 FP16 집계가 성공했다고 주장하지 않습니다. SP30은 변경 없는 동결 집계기를 사용했습니다. 실제 GPU UUID 값은 공개하지 않습니다.
- 공통으로 기록된 판정 런타임: NVIDIA A100-SXM4-80GB, float16, batch size 1, CUDA 13.0, cuDNN 91900, torch 2.11.0+cu130, transformers 5.20.2, accelerate 1.15.0, huggingface-hub 2.4.0, tokenizers 0.23.3. 이는 기록된 환경 정보이며 독립 반복 실험의 증거가 아닙니다.
- 두 조건의 원본 판정 1,272개에서 셀별 개수와 159개 고유 행동 ID를 다시 대조했습니다. 공개 CSV/JSON은 검증한 집계 자료의 동일 바이트 사본입니다. 공개 검증기는 이 파일들의 무결성과 집계 산술을 검사하지만 비공개 원문, 과거 실행 또는 모델 안전성을 재검증하지 않습니다.

## 해석 한계

1. 단일 seed, standard159의 기술적 비교입니다. 이 패키지에서는 유의성 검정, 신뢰구간, 인과 효과 또는 일반적 강건성을 주장하지 않습니다.
2. 평가자 간 불일치만으로 어느 평가자가 맞는지 결정할 수 없습니다. 인간 기준 안전성 정확도나 실제 피해 발생률을 뜻하지 않습니다.
3. 새 matched 실험은 이전 비교의 조건 불일치를 소급해서 해결하지 않습니다. 이전 [2026-11-04 결과와 정정](../2026-11-04_base_instruct/README.md)은 그대로 유지합니다.
4. SP40·50·55·60·70의 **새 matched 결과는 이 묶음에 없습니다**. 이전 조건의 수치를 새 matched 결과처럼 제시하지 않습니다.
5. 파일 해시는 바이트 동일성을 확인하는 수단이며 저자, 실행 사실 또는 과학적 타당성 자체의 증명은 아닙니다.
